## 🚀 Overview

This repository hosts the interactive web presentation for **SENARA** (`presentation-senara`), designed with dynamic fishing hook physics, dual-mode slide presentation, interactive Match Score simulation, financial breakdown, and the real soft-launch data from the *Business Men Day* launch event.

### Key Capabilities
- 🎣 **Interactive Animated Fishing Hook:** An animated monofilament fishing rig tracks progress and performs strike/wiggle animations as you navigate through slides.
- 🛡️ **Dual Verified Badge Architecture:**
  - 🟢 **Green Verified Badge:** Granted to job seekers upon portfolio vetting and skills verification.
  - 🔵 **Blue Verified Badge:** Granted to legitimate companies with verified commercial registries and tax credentials.
- ⚡ **Interactive Match Score Simulator:** Dynamic algorithm weighting skills (35%), portfolio (30%), experience (20%), and location (15%) with live circular dial feedback.
- 📊 **Soft Launch Database Traction:** Verified metrics from the initial event cohort (41 applications, 9 companies, 32+ seekers, 71 total QR scans, bulk Excel import hub).
- 💰 **200,000 EGP Capital Allocation:** Interactive SVG donut chart detailing software development, brand identity, marketing, and cloud infrastructure.
- 💼 **Monetization Engine:** Three scalable revenue streams (Tiered B2B employer subscriptions, promotional & skyscraper banner advertising, and digital transformation agency add-ons).
- 🌍 **Full Bilingual Arabic & English Support:** Instant toggle with complete RTL typography.
- 🎬 **Dual Presentation Modes:** Slide Deck Mode (<kbd>&rarr;</kbd> / <kbd>&larr;</kbd> / wheel / touch swipe) and Scrollytelling Continuous Flow.
- 🔊 **Web Audio Synthesized Effects:** Gentle rod reel clicks and water bite sounds with zero external audio assets.

## 🎮 Presentation Keyboard Controls

| Key | Action |
| --- | --- |
| <kbd>&rarr;</kbd> / <kbd>Space</kbd> / <kbd>PageDown</kbd> | Next Slide (Hook dives deeper) |
| <kbd>&larr;</kbd> / <kbd>PageUp</kbd> | Previous Slide |
| <kbd>M</kbd> | Toggle Slide Deck / Continuous Scroll Mode |
| <kbd>L</kbd> | Switch Language (English / العربية) |
| <kbd>F</kbd> | Toggle Fullscreen |
| <kbd>?</kbd> | Navigation Help Modal |
